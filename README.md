# Learning Kubernetes

Laboratório de estudos e práticas em Kubernetes, explorando conceitos fundamentais, workloads, networking, storage, segurança e GitOps.

## 🎯 Objetivo

Este repositório documenta minha evolução no aprendizado de Kubernetes, através de laboratórios práticos e exercícios.

- [x] Labels e Selectors
- [ ] Services
- [ ] Ingress
- [ ] ConfigMaps
- [ ] Secrets
- [ ] Volumes
- [ ] PersistentVolumes
- [ ] RBAC
- [ ] NetworkPolicies
- [ ] Probes
- [ ] Resources
- [ ] HPA
- [ ] Helm
- [ ] ArgoCD
- [ ] GitOps
- [ ] Kubernetes na AWS / EKS

## 🧪 Ambiente de laboratório

- Kubernetes
- Docker Desktop
- kubectl
- YAML
- Git / GitHub

## 🚀 Projeto final

Ao final dos estudos, será desenvolvido um projeto completo utilizando Kubernetes, integrando conceitos de containers, networking, persistência, segurança e GitOps.
